# Advanced Port Scanner 🔍

Advanced Port Scanner is a professional cybersecurity tool built with Python that helps security students, ethical hackers, and network administrators analyze network services and identify open ports on authorized systems.

The project provides a modern security dashboard with fast multi-threaded scanning, service detection, real-time scan updates, and detailed reporting features.

## 🚀 Features

* 🔹 TCP Port Scanning
* 🔹 Multi-threaded Fast Scanning
* 🔹 Port Range Scanning
* 🔹 Common Port Detection
* 🔹 Service Identification
* 🔹 Banner Grabbing
* 🔹 Target IP/Domain Resolution
* 🔹 Real-Time Scan Progress
* 🔹 Scan History Logging
* 🔹 PDF/CSV Report Generation
* 🔹 Cybersecurity Dashboard Interface
* 🔹 Error Handling and Timeout Management

## 🛠️ Technologies Used

* Python 3
* Socket Programming
* Threading
* Tkinter/PyQt5 GUI
* Networking Concepts
* Cybersecurity Fundamentals

## 📌 Project Purpose

This project is developed for educational purposes and authorized security testing. It helps users understand network reconnaissance, port analysis, and basic vulnerability assessment techniques.

## 🎯 Learning Outcomes

```bash

pip install -r requirements.txt
```

```bash
python main.py
```
